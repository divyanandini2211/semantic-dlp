----------------------------------------
EXECUTIVE SUMMARY
----------------------------------------

MeridianCompress v4 (MC4) is a proprietary lossless data compression algorithm
developed internally by the Meridian R&D team between 2024 and 2026. The core
innovation combines a modified Burrows-Wheeler Transform (BWT) with a custom
dynamic entropy encoding layer to achieve approximately 42 percent higher
throughput compared to standard bzip2 and zstd compression at equivalent
compression ratios.

----------------------------------------
TECHNICAL ARCHITECTURE
----------------------------------------

Stage 1 — Modified Burrows-Wheeler Transform (BWT)
  - Input: Raw byte stream (arbitrary data)
  - Processing: Applies a context-aware BWT that prioritizes high-frequency
    byte n-gram clusters over single-character permutation groups
  - Innovation: Uses a lookahead buffer of 512 bytes (vs standard 256) for
    superior local symbol run optimization

Stage 2 — Dynamic Entropy Encoding
  - Encoder Type: Adaptive Asymmetric Numeral Systems (ANS) with per-block
    probability table recalibration every 4KB of input
  - Throughput Gain: This adaptive recalibration is the primary driver of the
    42 percent throughput advantage in benchmark testing

Stage 3 — Block Interleaving & Checksum
  - Block Size: 1MB default (configurable: 256KB–16MB)
  - Interleaving: Parallel block encoding using 4-thread worker pool
  - Integrity: CRC-32C checksum per block; SHA-256 over full output stream
